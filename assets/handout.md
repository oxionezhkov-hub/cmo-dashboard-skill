# Раздатка участнику воркшопа

## Что нужно на входе

- [ ] Node.js 18+ (`node -v`)
- [ ] Claude Code
- [ ] OAuth-токен Яндекса (Директ + Метрика), номер счётчика, id цели «Заявка»
- [ ] Токен VK Ads, если есть закупка во ВКонтакте
- [ ] Ключ коллтрекинга и id сайта, если звонки считаются
- [ ] Токен интеграции CRM + поддомен
- [ ] Токен Telegram-бота и chat_id для дайджеста
- [ ] Google-таблица с планом: два столбца — метрика и план
- [ ] `ANTHROPIC_API_KEY`

Нет чего-то из списка — источник просто выключается в конфиге, остальные блоки соберутся. Доступы подставим позже.

## Команды воркшопа

```bash
# 1. Первая сборка: данные появятся в dashboard/data/
cd dashboard/collectors
node collect.js

# 2. Открыть дашборд
open ../index.html          # Windows: start ..\index.html

# 3. Свои доступы
cp config.example.json config.json    # заполнить, токены оставить в виде env:ИМЯ

# 4. Боевая сборка за конкретный период
DIRECT_TOKEN=... METRIKA_TOKEN=... AMO_TOKEN=... SHEETS_API_KEY=... \
  node collect.js --mode=live --from=2026-08-01 --to=2026-08-31

# 5. Инсайты через Claude + дайджест в Telegram
ANTHROPIC_API_KEY=... NOTIFY_BOT_TOKEN=... NOTIFY_CHAT_ID=... \
  node collect.js --mode=live --ai --notify

# 6. Проверить один источник: выключите остальные в config.json
node collect.js --mode=live

# 7. Собрать страницу для хостинга на воркере
cd .. && node build-worker-assets.mjs && wrangler deploy
```

## Три вопроса, на которые надо ответить до сборки

1. Что у вас считается заявкой?
2. Что делает заявку квалифицированной и кто это отмечает?
3. В какой момент сделка считается выигранной?

Без ответов дашборд соберётся, но цифры будут спорными.

## После воркшопа

1. Подключить оставшиеся источники.
2. Сверить прошлый месяц с кабинетами (расхождение >2% — баг).
3. Добавить своё правило в `insights.js`.
4. Настроить расписание и прислать скриншот первого дайджеста.
