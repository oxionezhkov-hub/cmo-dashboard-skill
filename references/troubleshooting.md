# Разбор проблем

## Данные не сходятся с кабинетом

| Симптом | Причина | Что делать |
|---|---|---|
| Расход отличается на ~20% | НДС: `IncludeVAT` в отчёте Директа | Зафиксировать один вариант и сверять с тем же режимом в интерфейсе |
| Расход больше в миллион раз | `returnMoneyInMicros` не выключен | `returnMoneyInMicros: 'false'` в заголовках |
| Сдвиг на один день | Часовые пояса: Директ в часовом поясе аккаунта, amoCRM в unix-времени | Приводить всё к одному поясу при нормализации, границы периода считать по нему же |
| Заявок в дашборде меньше, чем в CRM | Фильтр по `created_at` не забирает сделки, созданные в последний день периода | `to` = конец дня (23:59:59), а не полночь |
| Заявок больше, чем в отчёте маркетинга | В CRM попадают дубли и сделки из других воронок | Фильтровать по pipeline, чистить дубли по телефону/почте |

## Ошибки API

- **Директ 201/202** — это не ошибка, отчёт в очереди. Повторить через `retryIn` секунд.
- **Директ 400 с текстом про поля** — несовместимый набор полей в отчёте. Убирайте поля по одному.
- **Метрика 403** — у токена нет прав на счётчик. Проверьте, тем ли аккаунтом выдан OAuth.
- **amoCRM 401** — токен интеграции протух или скопирован с пробелом. 403 — интеграция не имеет прав на воронку.
- **amoCRM 204** — это конец пагинации, а не ошибка.
- **Sheets 403** — таблица не расшарена или API-ключ ограничен по домену.
- **429 где угодно** — слишком частые запросы; в `lib/http.js` уже есть ретрай с экспоненциальной паузой.

## Кривые данные

**Канал «не определён» у половины заявок.** Разметка сломана: нет UTM или поле в CRM заполняется руками.
Пока не починено — не стройте выводы по каналам, покажите долю неразмеченных заявок прямо на дашборде.

**Сделки без суммы.** Выручка считается только по выигранным сделкам с `price`. Если менеджеры
не заполняют сумму, ROMI будет занижен: либо чинить процесс, либо считать по среднему чеку и честно это подписать.

**Всплеск заявок в один день.** Обычно импорт базы или тест формы. Ищите по источнику и времени создания:
десять заявок в одну минуту — это не маркетинг.

## Дашборд не открывается / пустой

- `data/dashboard.js` не собран — запустите `node collect.js`.
- Открыт по `file://` и браузер ругается на `fetch` — дашборд специально читает `data/dashboard.js`
  скриптом, а не через `fetch`; проверьте, что тег `<script src="data/dashboard.js">` на месте.
- Графиков нет, в консоли `Chart is not defined` — не подгрузился `vendor/chart.umd.min.js`.
