# Скилл «Дашборд отдела маркетинга»

Скилл для Claude Code (и любого агента, который читает markdown-инструкции): собирает дашборд
отдела маркетинга со сквозной аналитикой — от вопросов клиенту и доступов до готовой страницы,
ИИ-выводов, автообновления и дайджеста руководителю.

Внутри — рабочий шаблон дашборда, который открывается двойным кликом и собирается одной командой,
поэтому первый результат виден через минуту после установки, ещё до получения доступов.

## Установка

### Claude Code — в текущий проект

```bash
mkdir -p .claude/skills
git clone --depth 1 https://github.com/oxionezhkov-hub/cmo-dashboard-skill .claude/skills/marketing-dashboard
rm -rf .claude/skills/marketing-dashboard/.git
```

Одной командой то же самое:

```bash
curl -sL https://raw.githubusercontent.com/oxionezhkov-hub/cmo-dashboard-skill/main/install.sh | bash
```

### Claude Code — во все проекты сразу

```bash
curl -sL https://raw.githubusercontent.com/oxionezhkov-hub/cmo-dashboard-skill/main/install.sh | bash -s -- --user
```

Скилл ляжет в `~/.claude/skills/marketing-dashboard` и будет доступен в любом проекте.

### Codex

У Codex нет отдельного формата скиллов — он читает `AGENTS.md`. Поэтому кладём папку в проект
и добавляем на неё ссылку:

```bash
curl -sL https://raw.githubusercontent.com/oxionezhkov-hub/cmo-dashboard-skill/main/install.sh | bash -s -- --codex
```

Скрипт положит скилл в `.agents/marketing-dashboard` и допишет в `AGENTS.md` строку:

> Задачи про дашборд маркетинга, сквозную аналитику и ИИ-выводы по рекламе — работать по инструкции
> `.agents/marketing-dashboard/SKILL.md`, начиная с вопросов из неё.

Если `AGENTS.md` ведёте руками — добавьте эту строку сами, скрипт ничего не перезапишет.

### Вручную

Скачайте архив репозитория и распакуйте в `.claude/skills/marketing-dashboard` — в скилле нет
зависимостей и шагов сборки, это просто папка с markdown и шаблоном.

## Как пользоваться

В Claude Code:

```
/marketing-dashboard
```

или просто словами: «собери дашборд отдела маркетинга», «нужна сквозная аналитика по рекламе»,
«помоги подготовить воркшоп по дашборду».

Агент начнёт с вопросов — чем пользуетесь, какие воронки, кто читатель дашборда, какой дизайн,
где хостить, какая модель для ИИ-выводов, как часто обновлять — и только потом возьмётся за доступы
и сборку. Это специально: дашборд, собранный без этих ответов, показывает красивую неправду.

Быстрый старт без доступов — шаблон уже лежит внутри скилла:

```bash
cp -r .claude/skills/marketing-dashboard/assets/dashboard ./dashboard
cd dashboard/collectors && node collect.js
open ../index.html
```

Нужен только Node 18+. Пакеты ставить не нужно.

## Что внутри

```
SKILL.md                   главная инструкция: фазы, правила, маршрутизация
references/
  brief.md                  вопросы клиенту и бриф
  secrets.md                где взять каждый токен и куда его вставить
  connectors.md             API девяти источников и типичные грабли
  data-model.md             единая модель данных и контракт коннекторов
  insights.md               правила для выводов и промпт для модели
  automation.md             расписание, кнопка обновления, дайджест, хостинг
  testing.md                чек-лист перед сдачей работы
  troubleshooting.md        почему цифры не сходятся с кабинетом
  workshop.md               сценарий воркшопа на 3 часа с таймингом
assets/
  brief-template.md          шаблон брифа
  handout.md                 раздатка участнику воркшопа
  dashboard/                 рабочий шаблон дашборда, который копируется в проект
```

## Что умеет собранный дашборд

- Девять источников: Яндекс.Директ, VK Ads, Telegram Ads, Яндекс.Метрика (включая поведение
  на страницах из Вебвизора), коллтрекинг, amoCRM, Telegram-бот, Google Sheets.
- Сквозная аналитика: видно, сколько продаж и выручки принесла каждая кампания.
- Переключение периода 7 / 14 / 28 дней прямо в браузере, без пересборки.
- Разворот каждого раздела в попап с фильтрами, сортировками и детальными таблицами.
- ИИ-выводы в два слоя: правила считают аномалии, модель формулирует вывод и действие.
- Блок вопросов к ИИ по цифрам текущего периода.
- Обновление по расписанию (GitHub Actions или cron воркера) и по кнопке.
- Дайджест руководителю в Telegram — только когда есть что сказать.

Токены никуда не уезжают: в конфиге хранятся ссылки вида `"env:AMO_TOKEN"`, сам `config.json`
в `.gitignore`.
